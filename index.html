오늘·어제·30일 통계와 백만 토큰당 비용 비교. iCloud로 여러 Mac의 사용 이력 합산.

Codex 초기화 예측과사용 가능한 리셋을 한눈에.

Reset Watch는 비공식 공개 예측. 개인 한도 초기화를 보장하지 않으며, 새 예측 알림은 설정에서 선택.

내가 정한 사용 한도를막대 위 안내선으로 확인하세요.

5시간·주간 중 선택하고 1–100%로 설정. 현재 자동 작업 취소는 지원하지 않음.

여러 계정을 등록하고필요한 계정으로 전환하세요.

Claude·Codex 계정을 한 카드 또는 개별 카드로 표시. 대시보드의 계정 선택은 조회용이며, 실제 전환은 설정이나 우클릭 메뉴에서 확인 후 실행.

CLI와 로컬 API로사용량을 도구와 연결하세요.
