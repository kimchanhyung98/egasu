# pstack

[poteto-mode](skills/poteto-mode/SKILL.md)를 읽고 요청에 맞는 절차 선택.
각 문서의 상대 경로는 해당 문서의 디렉터리 기준으로 해석.
프로젝트의 AGENTS.md와 사용자가 지정한 작업 범위 우선 적용.
커밋과 푸시는 사용자의 명시적 요청이 있을 때만 실행.
