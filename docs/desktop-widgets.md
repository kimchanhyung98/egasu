# macOS 데스크톱 위젯

egasu의 Priority 또는 선택한 계정의 사용량을 데스크톱에 표시.
같은 크기의 위젯도 각각 다른 계정과 지표를 선택 가능.

## 위젯 추가

1. Mac 바탕화면을 우클릭하고 **위젯 편집** 선택.
2. 갤러리에서 **egasu** 검색.
3. 소형·중형·대형 중 원하는 크기로 추가하고 **완료** 선택.

새 위젯은 항상 **Priority(우선순위)**로 시작.
앱의 고정 지표와 우선순위 조건을 보드 순서대로 표시.
조건을 모두 끄면 위젯에 우선순위 표시가 꺼진 상태를 안내. [우선순위 조건](/docs/settings.md#우선순위)

## 특정 계정의 지표 표시

1. 바탕화면에 놓은 해당 위젯을 우클릭하고 **egasu 편집** 선택.
2. **표시 방식**에서 **전체 사용량(All Usage)** 선택.
3. **계정별 지표**에서 원하는 계정과 지표가 함께 표시된 항목 선택.
4. 추가할 항목을 모두 고른 뒤 편집 완료.

예를 들어 Codex의 `a` 계정에서 `Weekly` 하나만 고르면 이 위젯에는 그 계정의 주간 한도만 표시.
다른 계정의 `Weekly`나 Cursor의 `Today`도 같은 위젯에 추가 가능.
지표 후보와 계정 안의 지표 순서는 앱의 All Usage 표시 설정을 따름.
위젯에서 고른 항목은 위젯별로 저장.
앱에서 계정을 삭제하면 해당 자리에는 사용 불가 상태 표시.

## 갱신과 개인정보

앱이 조회한 사용량과 마지막 관측 시각을 이 Mac의 위젯과 공유.
앱이 종료된 동안 위젯은 마지막 관측값을 표시하며, 조회 주기의 두 배가 지나면 오래된 값으로 표시.
구독 타이머 자동 시작 경고는 사용량 조회 상태와 별도로 처리.
Priority 위젯은 앱과 같은 확인 필요 계정을 표시하며, 경고 상세는 egasu 앱에서 확인.
Priority의 예상 소진 시각이 지나면 남은 시간 표시를 마치고 마지막 관측값 유지.
초기화 예정 시각이 지나도 새 사용량은 다음 조회에서 확인.
데스크톱에 새 값이 실제로 나타나는 시점은 macOS가 결정. [Apple의 위젯 갱신 안내](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date)

Privacy Mode를 켜면 앱이 위젯에 전달하는 계정 이름도 가림.
macOS가 이미 그린 위젯은 다음 갱신까지 이전 모습이 보일 수 있음. [개인정보](/docs/privacy.md)
