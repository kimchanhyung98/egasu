# 메뉴 막대

선택한 기준에 맞는 지표를 Priority 보드에서 골라 메뉴 막대에 표시.

메뉴·사용량 설명·접근성 문구는 [Settings → General](/docs/settings.md#general)의 Language 선택에 따라 표시.
변경한 언어는 앱 재실행 후 적용하며 프로바이더 이름과 사용자 계정명은 원문 유지.

## 아이콘 우클릭

메뉴 막대 아이콘을 우클릭(또는 Control-클릭)하면 **Accounts**, **Settings**, **Quit egasu** 빠른 메뉴.
좌클릭으로 패널 열기.

## 표시 항목

설정 위치: [Settings → Display → Menu Bar Icons](/docs/settings.md#menu-bar-icons).

- **Icon Style**에서 Text(프로바이더 마크·이름·값) 또는 Bars(한 아이콘에 쌓은 막대) 선택.
  저장값이 없으면 기본값 Text.
  선택은 즉시 적용하고 앱 재실행 뒤에도 유지.
- **Menu Bar Items**에서 표시 기준 선택.
  - **Running Out**(기본): 곧 소진될 한도만 표시.
  - **Priority**: 고정 → 소진 임박 → 초기화 전 사용 → 소진됨 순서.
    고정한 지표는 소진 완료여도 앞쪽 고정 목록과 저장 순서 유지.
    고정하지 않은 소진됨 항목은 남는 칸에만 표시하고 `+N`에 세지 않음.
  - **Pinned Only**: 직접 고정한 지표만 저장된 계정·지표 순서로 표시.
    고정하지 않은 소진 임박 항목은 추가하지 않음.
    고정한 지표는 소진 임박·소진 완료로 바뀌어도 같은 순서 유지.
- **Max Items In Menu Bar**(기본 3개)까지 표시.
- **Show Extra Indicators**(추가 표시, 기본 켬)는 넘친 항목 수(`+N`)와 업데이트 표시 제어.
  끄면 Text·Bars 양쪽에서 이 두 표시를 숨기며, Bars는 막대 아이콘만 표시.
  선택은 즉시 적용하고 앱 재실행 뒤에도 유지.
  macOS 알림과 업데이트 확인·대시보드 안내는 각 설정에 따라 유지.
- 표시할 항목이 없으면 egasu 아이콘.
  Pinned Only에서 고정한 지표가 없을 때도 동일.
- **App Icon Only**를 고르면 항상 egasu 아이콘.
- Text는 항목마다 프로바이더 마크 · 짧은 지표 이름 · 값.
  같은 프로바이더 계정이 여럿이면 마크 오른쪽 아래에 계정 이니셜.
- Bars는 선택한 표시 기준과 순서로 최대 5개 막대를 위에서 아래로 표시.
  막대를 그릴 한도가 없는 지표는 개수 제한 전에 제외.
  채움 방향은 **Show Usage As**의 Used / Left 설정 적용.
- 데이터가 없는 행(조회 실패한 예측 등)은 자리를 차지하지 않음.
- 추가 표시가 켜져 있고 업데이트가 있으면 오른쪽 위에 점이 붙은 앱 아이콘 표시.
- 자동 선택의 순위가 시간에 따라 바뀌는 동안 30초마다 다시 그림.
  Reset Watch 예측 만료와 Priority의 Use It or Lose It 진입·종료 시각에도 다시 그림.
  화면 갱신을 위해 별도 네트워크 요청을 보내지 않음.

**Menu Bar Items** 저장값이 없으면 **Always Show In Menu Bar**의 저장값 승계: 켜짐은 Priority, 꺼짐은 Running Out.

## 고정과 이전 별표

- 고정 방법과 규칙은 [대시보드 § 고정](/docs/dashboard.md#고정) 참조.
- 메뉴 막대 별표 설정이 남아 있으면 첫 실행에 한 번 Priority 고정으로 이전.
  - 기본 별표를 그대로 쓰던 경우는 이전하지 않음.
  - 숨긴 지표의 별표는 버림.
  - Claude·Codex 별표는 그때 알려진 모든 계정의 같은 지표로 펼침(추가 계정에서 숨기는 로컬 기록·Reset Watch 제외).
  - 이전하면 **Menu Bar Items**를 Priority로, **Max Items In Menu Bar**를 고정 수에 맞춤(3~5개).

## 화면 공유 중 사용량 숨기기

**Settings → Advanced → Privacy → Privacy Mode**(개인정보 보호 모드, 기본값 켬).
화면 공유·녹화를 감지하면 메뉴 막대의 사용량을 egasu 아이콘으로 대체.
직접 시작한 화면 녹화도 감지 대상에 포함.
캡처 종료를 감지하면 선택한 표시로 복귀.

macOS의 화면 캡처 상태와 변경 알림으로 감지.
설정이 켜져 있는 동안 3초마다 상태 재확인.
감지 기능을 사용할 수 없으면 macOS 원격 화면 공유만 확인 가능하며, Zoom·Meet·Teams 등 앱의 공유·녹화는 감지하지 못할 수 있음.
감지가 늦거나 지원되지 않는 캡처에서는 사용량이 보일 수 있음.
