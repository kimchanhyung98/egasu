# OpenCode

Go 키가 있으면 서버에서 계정 전체의 세션·주간·월간 사용률과 초기화 시각 조회.
Go와 Console의 지출·토큰은 이 Mac의 사용 기록에서 집계.
구독 가격과 현행 라인업은 [구독 요금제](/docs/pricing.md#구독-요금제) 참조.
원본 로그는 이 Mac에서만 읽음.

## 추적 항목

| 지표 | 의미 |
|---|---|
| Session | 서버의 5시간 사용률과 초기화 시각 |
| Weekly | 서버의 주간 사용률과 초기화 시각 |
| Monthly | 서버의 월간 사용률과 초기화 시각 |
| Today / Yesterday / Last 30 Days | 모든 OpenCode 호스팅 사용량(Go + Console)의 로컬 비용과 토큰 |
| Usage Trend | 오늘과 이전 30일의 일별 토큰 막대 차트 |

서버에서 확인한 기간만 표시.
미시작 세션으로 판단되는 0% 응답은 초기화 카운트다운 생략.
일부 기간이 누락되면 확인한 값을 유지하고 경고 표시.
실측값이 전혀 없고 이 Mac에 Go 사용 기록이 있으면 같은 행에 달러 추정치 표시.
이전 고정·숨김 설정과 지표 순서 유지.
Soft Limit 사전 검사는 서버에서 확인한 주간·월간 값만 사용.

## 인증 정보 출처

평소처럼 OpenCode 사용.
egasu가 Go 사용량을 조회할 때 다음 순서로 인증 정보 확인.

1. `OPENCODE_AUTH_CONTENT`가 유효한 JSON이면 해당 값에서 `opencode-go` 키 확인.
2. 변수가 없거나 JSON 해석에 실패하면 로컬 데이터 디렉터리의 `auth.json`에서 확인.
3. 선택된 인증에 사용 가능한 Go 키가 없으면 `OPENCODE_GO_API_KEY` 사용.

프로젝트의 `provider.options.apiKey`나 플러그인이 다른 키를 지정하면 OpenCode가 사용하는 계정과 egasu가 조회하는 계정이 다를 수 있음.
앱과 CLI는 실행할 때마다 위 순서로 선택한 키로 계정 한도 조회.
사용액과 토큰 수는 SQLite 로그에서 계산.
egasu가 OpenCode 데이터 디렉터리를 다음 순서로 결정:

1. egasu 전용 환경 변수 `OPENCODE_DATA_DIR`이 설정돼 있으면 해당 경로 사용.
2. 그 외에 `XDG_DATA_HOME`이 설정돼 있으면 `$XDG_DATA_HOME/opencode` 사용.
3. 두 환경 변수가 모두 없으면 `~/.local/share/opencode` 사용.

`OPENCODE_DB`가 설정돼 있으면 해당 DB만 조회.
절대 경로는 그대로, 상대 경로는 위 데이터 디렉터리 기준으로 해석.
셸에서 확장되지 않은 `~/` 값도 데이터 디렉터리 아래 상대 경로로 해석.
`:memory:`는 다른 프로세스에서 읽을 디스크 로그가 없어 수집 불가.
DB 경로를 바꿔도 `auth.json` 위치는 데이터 디렉터리 기준 유지.

로그인 프롬프트나 붙여 넣을 토큰 불필요.

## 미터와 지출 타일

### 비용과 토큰 집계

`step-finish` 기록이 있으면 각 step의 비용과 토큰을 합산.
step 기록이 없는 메시지는 메시지에 기록된 비용과 토큰 사용.
달러 금액을 egasu에서 다시 계산하지 않음.
토큰 `total`이 없으면 입력·출력·추론·캐시 읽기·캐시 쓰기를 한 번씩 합산.
토큰 필드 자체가 없으면 비용은 유지하고 토큰은 0으로 처리.
토큰 필드가 있지만 값이 잘못되면 해당 기록 제외.
세션 fork가 복사한 과거 사용량은 중복 합산에서 제외.
같은 프로젝트에서 세션 생성 전 시각과 메시지 내용이 일치하는 기록을 복사본으로 판별.
비용 기록 후 fork하고 원본의 완료 시각·종료 상태·구조화 출력이 바뀌어도 같은 소비는 한 번만 합산.
같은 세션에 시각·내용이 동일한 메시지가 여러 개 있으면 각각의 소비 보존.
복사본만 남으면 세션별 동일 기록의 최대 개수만큼 유지.
fork 이후의 새 요청과 각 세션에서 새로 생성한 요청은 각각 합산.
OpenCode 버전에 따라 기록값 자체가 카탈로그 단가로 계산한 추정 비용일 수 있으며, 실제 청구액·Go 할당량과 다를 수 있음.
OpenCode 자체 기록이 포함된 기간의 지출은 추정 비용으로 표시하고 내보낸 이력도 추정 비용으로 분류.
각 지출 타일은 Claude / Codex / Cursor와 동일하게 비용과 토큰을 함께 표시(`$4.08 · 1.2M tokens`).
검사 범위는 지출 타일보다 넓은 월간 Go 기간까지 포함.
현재 지출 타일과 Go 기간에 속하지 않는 과거 기록은 비용 합산에서 제외.
Console 기록은 지출 타일 기간에만 반영.
큰 유한 비용은 반올림 과정에서도 그대로 유지해 사용량 스냅샷 저장 가능.
누락된 기간 행에는 대시보드의 [기간 값 표시 규칙](/docs/dashboard.md#한도가-없는-지표) 적용.
로컬 DB를 읽지 못해 공유 도구 기록만 표시한 경우, 값이 없는 기간 행에는 **No data** 표시.
표시용 0은 상단 비용·토큰 합계에 추가하지 않음.
Usage Trend는 토큰 기록이 없으면 **No data** 표시.
사용 기록이 없어도 서버가 반환한 0%는 표시.
숫자가 아닌 메시지 비용은 SQL 조회 단계에서 제외하며 별도 진단 로그 없음.
파서가 거부한 비용·토큰이나 합산 범위를 넘기는 행은 지출 타일·추세·Go 사용량에서 제외하고 진단 로그에 기록.
나머지 정상 행은 계속 반영.

### 서버 실측이 없을 때의 로컬 추정

egasu의 로컬 추정 상한은 **5시간당 $12**, **주당 $30**, **월당 $60**.
추정 상한은 구독 등급과 무관하며 자동 차단에서 제외.

- **Session:** 최근 5시간의 기록 합산.
  사용 기록이 있으면 카운트다운은 가장 오래된 기록이 집계에서 빠지는 시각.
  이후 기록이 남아 있으면 그 시각에도 사용액이 0보다 클 수 있음.
- **Weekly:** UTC 월요일부터 다음 월요일까지의 기록 합산.
- **Monthly:** 이 Mac에서 읽은 가장 이른 Go 기록의 UTC 날짜·시각으로 월간 경계 계산.
  해당 날짜가 없는 달에는 그 달의 마지막 날짜 사용.
  최초 Go 기록을 확인하지 못하면 UTC 기준 매월 1일부터 집계.

Console 사용량은 Go 상한 계산에서 제외하고 지출 타일과 Usage Trend에 반영.

공유 도구가 `opencode` 또는 `opencode-go`로 기록한 사용량도 지출·토큰 이력에 반영.
추가 기록의 비용은 제공자가 보고한 금액만 사용하며 가격을 모르는 기록의 토큰은 유지.
해당 기간의 비용이 불완전하면 전체 비용·Cost/MTok 생략.
추가 도구의 기록은 Go 미터의 기간·상한 계산에 합산하지 않음.

## 문제 해결

- **지출·Usage Trend에 기록이 없음** — `OPENCODE_DB`를 설정했다면 지정한 DB 확인.
  설정하지 않았다면 데이터 디렉터리의 `opencode*.db` 확인.
  OpenCode 사용 기록이 저장된 뒤 새로 고침.
  Go 키만 있는 경우에는 서버 조회 결과 확인.
- **Session / Weekly / Monthly 미터가 없음** — 로컬 Go 키나 지출·Go 집계 범위 안의 Go 기록이 있는지 확인.
  집계 범위 밖의 과거 기록만으로는 상한 미터가 나타나지 않음.
  집계 기간의 기록이 남아 있으면 구독 만료 뒤에도 로컬 추정치 표시 가능.
- **"Couldn't read OpenCode's local database"** — 데이터베이스(또는 데이터 디렉터리)가 있지만 이번 새로 고침에서 읽지 못한 상태.
  OpenCode를 종료하고 새로 고침한 뒤에도 문제가 계속되면 설정한 DB 또는 데이터 디렉터리의 접근 권한 확인.
- **일부 로컬 사용량 파일을 읽지 못했다는 안내** — OpenCode DB 또는 Pi·OMP 같은 공유 도구 저장소를 일부 읽지 못한 상태.
  각 저장소의 경로·접근 권한 확인.
  DB를 사용하는 저장소는 잠금 상태도 확인.
  문제를 해결한 뒤 다시 새로 고침.
- **"Couldn't read OpenCode's auth.json"** — 파일이 있지만 읽을 수 없거나 유효한 JSON이 아닌 상태.
  읽을 수 있는 로컬 사용 이력은 경고와 함께 표시.
  권한을 확인하거나 OpenCode Go에 다시 로그인해 파일 재작성.
- **수치가 대시보드보다 낮음** — 달러 추정치와 지출 이력은 이 Mac에서 관측한 범위.
  백분율은 서버가 보고한 계정 사용률.

## 내부 동작

`OPENCODE_DB`가 없으면 데이터 디렉터리의 모든 `opencode*.db` 조회.
설정돼 있으면 지정한 DB 하나만 조회.
V1 `message`·`session` 및 선택적인 `part` 테이블 지원.
V2의 `session_message`·`session_v2` 및 자격 증명 DB는 미지원.
안정 릴리스는 `opencode.db`, 일부 개발 채널은 `opencode-<channel>.db` 사용.
조회한 DB의 어시스턴트 메시지에서 `cost`와 토큰 필드를 읽음.
Go 상한에는 `opencode-go` 메시지를 합산하고, 지출 타일과 추세에는 `opencode-go`(Go)와 `opencode`(Console)를 모두 합산.
로컬 식별자 `opencode`와 과거 Zen 기록도 같은 Console 범위에 포함.
OpenCode 로컬 DB와 지원 공유 도구 기록을 읽기 전용으로 조회.
CLI의 일반 조회는 현재 터미널에서 받은 키와 데이터 디렉터리를 사용.
소프트 한도 사전 검사는 OpenCode 명령과 같은 로그인을 확인하기 위해 egasu 전용 `OPENCODE_DATA_DIR`를 제외하고 터미널의 XDG 경로 사용.
현재 키의 계정을 검증할 수 없는 이전 실행의 사용량은 재사용하지 않음.
Go 키는 OpenCode 공식 사용량 주소 `https://opencode.ai/zen/go/v1/usage`에만 전송.

## 공유 도구 사용량

공통 수집 대상은 Pi·Oh My Pi(OMP).
도구별 경로·중복 제거·가격 규칙은 [사용량 수집](/docs/usage-collection.md) 참조.
계정 귀속을 확인하지 못하는 기록은 계정 전용 카드에 합산하지 않음.
공통 수집이 실행되면 읽지 못한 저장소를 경고하고 읽은 기록은 보존.
공유 도구 기록에는 제공자가 보고한 비용만 사용하며 단가표 추정액은 합산하지 않음.
토큰이 양수인 기록에 보고 비용이 없으면 토큰은 보존하고 해당 기간의 총비용 생략.
OpenCode 원장을 읽지 못해도 서버의 Go 사용률과 공유 도구의 정상 이력은 유지.
서버 사용률과 공유 도구의 정상 이력이 모두 없으면 원장 읽기 오류를 반환하고 마지막 정상 이력 유지.
로컬 키나 OpenCode 자체 사용 이력이 없어도 최근 집계 기간에 유효한 공유 도구 OpenCode 이력이 있으면 로컬 감지 대상에 포함.
다른 프로바이더 기록이나 정상 빈 공유 파일만으로는 자동 활성화하지 않음.
이미 활성화한 카드는 OpenCode 원장과 공유 도구를 합친 이력이 정상적으로 비어 있으면 이전 이력을 비우고 위 기간 표시 규칙 적용.
OpenCode 원장이 없고 공유 이력이 빈 경우에도 `auth.json` 접근 실패는 경고로 안내하며, 완료된 빈 이력은 유지.
Go 키·OpenCode 원장·공유 스캔 결과가 모두 없으면 감지되지 않음 오류 반환.
