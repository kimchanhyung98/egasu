# 설정

설정은 패널 안에 있음 — 별도 창 없음.
푸터 ⋯ 메뉴의 **Settings**, 패널이 열린 상태의 ⌘, 단축키, 메뉴 막대 아이콘 우클릭 후 **Settings** 중 하나로 열기.
위쪽 탭으로 **General**, **Display**, **Alerts**, **Advanced** 전환.
**일반 → 업데이트 → 베타 업데이트**를 켜면 다섯 번째 탭 [실험실(Labs)](/docs/settings.md#labs) 표시.
언어를 제외한 변경은 즉시 적용.
설정 이름 옆 ⓘ에 포인터를 올리면 설명 표시.
왼쪽 위 뒤로 가기 버튼, ⌘, 단축키, Esc로 대시보드에 복귀(Esc는 대시보드로 먼저 돌아가며, 한 번 더 누르면 패널 닫기).

## General

| 설정 | 옵션 | 동작 |
|---|---|---|
| Launch at Login(로그인 시 실행) | 켜기 / 끄기 | 앱을 로그인 항목으로 등록(시스템의 로그인 항목 레지스트리가 기준).<br>Settings를 열 때마다 시스템의 현재 등록 상태를 다시 읽음. |
| Auto-Start Subscription Timers(구독 타이머 자동 시작) | 켜기 / 끄기 | 기본값 켜짐.<br>모든 지원 계정의 미사용 구독 구간을 짧은 메시지로 시작하며, 이후 추가한 계정에도 같은 설정 적용.<br>끄면 전송 대기 중인 메시지를 포함해 새 자동 전송을 중지하고 사용량 조회는 계속.<br>[지원 한도와 전송 조건](/docs/refreshing.md#구독-타이머-자동-시작) 참조. |
| Default Tab(기본 탭) | Priority / All Usage | 앱 시작 시 열 탭 선택(기본값 Priority).<br>패널만 닫았다 열면 마지막 선택 탭 유지.<br>기본 탭을 바꾸면 현재 탭도 전환.<br>우선순위 표시를 모두 꺼 둔 동안에는 전체 사용량을 열고, 조건을 다시 켜면 선택한 탭 표시. |
| Global Shortcut(전역 단축키) | 키 조합 지정 | 어디서든 패널을 토글하는 전역 단축키.<br>필드를 클릭하고 조합키 입력, ⓧ를 누르면 지워지고 단축키 비활성. |
| Language(언어) | English / 한국어 / 日本語 | 앱 표시 언어.<br>기본값은 English.<br>선택한 언어는 앱을 다시 실행할 때 적용. |

Launch at Login 변경이 실패하면 현재 설정 화면의 General에 오류 표시.
General에 들어올 때마다 시스템 상태를 다시 읽고, 요청한 상태와 일치하면 오류 안내 해제.
같은 앱 실행 중에는 Settings 밖으로 이동해도 해결되지 않은 로그인 시 실행·언어 재시작·Terminal Helper 오류 안내 유지.

단축키 설정은 KeyboardShortcuts 기본 입력기 사용.
기존에 저장한 키 조합 유지, 시스템·메뉴 단축키와 충돌하면 입력기에서 안내.
지정 전과 입력 대기 중 안내 문구는 앱 표시 언어 사용.
입력 대기 중에는 앱의 전역 단축키 실행을 잠시 중지.
Esc, General 이탈, 패널 닫힘 또는 다른 창으로 포커스 이동 시 입력 취소.
취소 시 저장한 키 조합을 유지하고 기존 전역 단축키를 다시 활성화.

최초 실행은 항상 English로 시작.
앱 언어는 macOS 언어를 자동으로 따르지 않으며 사용자가 직접 선택.
현재 실행 언어와 다른 언어를 선택하면 재시작 안내와 **Restart Now(지금 다시 시작)** 버튼 표시.
버튼을 누르면 기존 앱을 정상 종료한 뒤 같은 앱을 다시 실행해 선택한 언어 적용.
현재 실행 언어로 되돌리면 안내와 버튼 숨김.
재시작 준비에 실패하면 앱을 유지하고 오류 안내 표시.
기존 앱 종료 후 다시 실행하지 못하면 별도 오류 대화상자에서 수동 실행 안내.
실행 중인 화면은 기존 언어를 유지하며, 앱이 자동으로 종료되지는 않음.
대시보드·Accounts·설정·메뉴·알림·공유 이미지에 같은 언어 적용.
프로바이더·모델명, 사용자가 지정한 계정명, 명령 출력, 로그는 원문 유지.
금액은 언어와 관계없이 USD이며 통화 환산 없음.
언어 선택은 이 앱에만 저장하며 macOS 전체 언어 설정은 변경하지 않음.

0.7 이전 에디션의 로그인 런처 파일이 남아 있으면 앱 실행 시 확인.
현재 앱 번들 내부를 가리키는 파일만 자동 제거하며, 로그인 시 실행은 **Launch at Login**으로 관리.

### 화면 표시

테마와 시간 형식은 General의 **Appearance**에서 변경.

| 설정 | 옵션 | 동작 |
|---|---|---|
| Theme(테마) | System / Light / Dark | 패널에 적용할 앱 전체 화면 스타일 재정의. |
| Time Format(시간 형식) | Auto / 12-hour / 24-hour | 정확한 시각을 읽는 방식(예: "Resets today at 6:38 PM" 대 "18:38").<br>기본값은 24-hour, Auto는 시스템을 따름. |

### iCloud 동기화

**Sync Across Macs**(Mac 간 동기화)는 기본값 꺼짐.
켜면 앱의 비공개 iCloud 컨테이너로 정규화된 egasu 기록을 공유하고, 같은 iCloud 계정으로 로그인한 Mac들의 로컬 토큰과 지출을 합산.
사용량 갱신 후 기록 저장.
정기 갱신 주기는 일반 5분·Claude 15분.
설정에는 Mac별 상대 **Updated** 시각이 표시되며, iCloud 사용 불가·불러오기·저장·잘못된 파일 형식 상태도 함께 표시.
무엇이 포함되고 어느 화면이 합산 값을 쓰는지는 [iCloud 동기화](/docs/icloud-sync.md) 참조.

### 업데이트

업데이트 피드가 없는 개발 빌드에서도 **Beta Updates**로 실험실을 열 수 있음.
이때 **Check Automatically**와 **Check for Updates…**는 비활성.
베타 업데이트 선택은 이 Mac에 저장하며 iCloud 동기화 대상에서 제외.
개발 앱과 배포 앱의 설정은 서로 독립.

| 설정 | 옵션 | 동작 |
|---|---|---|
| Check Automatically(자동으로 확인) | 켜기 / 끄기 | 기본값은 끄기.<br>켜면 Sparkle이 백그라운드에서 업데이트 확인.<br>기존에 저장한 선택 유지.<br>꺼 두어도 수동 확인은 가능. |
| Beta Updates(베타 업데이트) | 켜기 / 끄기 | 켜면 실험실 탭 표시.<br>업데이트 피드가 있는 앱에서는 정식 버전과 베타 버전 모두 수신. |
| Check for Updates…(업데이트 확인…) | 버튼 | 수동 업데이트 확인을 시작하고 Sparkle 업데이트 창 열기. |

대시보드 배너, 채널, 서명 검증은 [업데이트](/docs/updates.md) 참조.

## Display

### 메뉴 막대 아이콘

Display의 **Menu Bar Icons** 미리보기는 고른 스타일·개수와 추가 표시 설정을 예시 항목에 적용.
현재 사용량은 미리보기에 반영하지 않음.

| 설정 | 옵션 | 동작 |
|---|---|---|
| Icon Style(아이콘 스타일) | Text / Bars | Text는 프로바이더 마크·지표 이름·값, Bars는 한 아이콘에 쌓은 막대.<br>저장값이 없으면 기본값 Text.<br>즉시 적용하고 재실행 뒤에도 유지.<br>Bars는 한도가 있는 지표만 표시하며 Used / Left 설정 적용.<br>App Icon Only에서는 비활성. |
| Show Metric Labels(지표명 표시) | 켜기 / 끄기 | 기본값 켜기. Text 스타일에서 지표명 표시. 계정명을 표시하는 항목에서는 한도 기간을 배지로 표시. |
| Show Account Names(계정명 표시) | 켜기 / 끄기 | 기본값 끄기. Text 스타일에서 등록한 계정명을 값 위에 표시. 개인정보 보호 모드에서는 계정명과 이니셜 숨김. |
| Show Reset Countdown(초기화까지 남은 시간 표시) | 켜기 / 끄기 | 기본값 끄기. Text 스타일에서 향후 초기화 시각이 있는 퍼센트 한도의 값 옆에 남은 시간 표시. |
| Max Items In Menu Bar(메뉴 막대 최대 항목) | App Icon Only / Up to 1 ~ Up to 5 | 선택한 기준에 맞는 지표의 표시 개수 제한.<br>기본값은 Up to 3.<br>추가 표시가 켜져 있으면 넘친 항목 수를 `+N`으로 표시.<br>App Icon Only는 항상 egasu 아이콘 표시.<br>[메뉴 막대](/docs/menu-bar.md) 참조. |
| Menu Bar Items(메뉴 막대 표시 항목) | Running Out / Priority / Pinned Only | 기본값 Running Out은 고정 여부와 관계없이 소진 임박 한도 표시.<br>Priority는 Pinned → Running Out → Use It or Lose It → Used Up 순서이며 고정한 지표는 소진 완료여도 앞쪽 고정 목록 유지.<br>Pinned Only는 직접 고정한 지표만 저장된 계정·지표 순서로 표시.<br>저장한 표시 기준이 있으면 유지.<br>저장값이 없고 이전 **Always Show In Menu Bar**가 켜져 있으면 Priority, 그 외 Running Out.<br>App Icon Only에서는 비활성.<br>[표시 기준](/docs/menu-bar.md#표시-항목) 참조. |
| Show Extra Indicators(추가 표시) | 켜기 / 끄기 | 메뉴 막대의 생략된 항목 수(`+N`)와 업데이트 표시 제어.<br>기본값 켜기.<br>끄면 Bars는 막대 아이콘만 표시.<br>즉시 적용하고 재실행 뒤에도 유지.<br>macOS 알림·업데이트 확인·대시보드 안내와 독립. |

### 전체 사용량 레이아웃

Display의 **Appearance** 구역에서 선택.

| 설정 | 옵션 | 동작 |
|---|---|---|
| All Usage Layout(전체 사용량 레이아웃) | Minimal / Cards | All Usage의 미니멀 목록 또는 계정별 독립 카드 선택.<br>기본값은 Minimal.<br>즉시 적용하며 앱 재실행 뒤에도 선택 유지.<br>계정·지표 순서, 숨김·고정과 사용량은 두 방식에서 공유. |

### 사용량

Display의 **Usage**에서 사용량 값·초기화 시각·사용 속도·총 지출의 표시 방식 설정.

| 설정 | 옵션 | 동작 |
|---|---|---|
| Show Usage As(사용량 표시 방식) | Used / Left | 상한이 있는 지표를 "48% used"로 읽을지 "52% left"로 읽을지.<br>기본값은 Used.<br>대시보드·메뉴 막대·공유 이미지에 적용. |
| Reset Times(초기화 시각) | Countdown / Exact Time | "Resets in 3h 25m" 대 "Resets today at 6:38 PM".<br>기본값은 Exact Time.<br>Codex Reset Watch의 예측·예정 시각에도 적용. |
| Pace Marks(사용 속도 표시) | 켜기 / 끄기 | 막대와 Priority 링에, 기간 내내 고르게 썼다면 지금 도달했을 위치를 눈금으로 표시.<br>기본값은 끄기.<br>이 항목의 저장값이 없고 **Always Show Pacing**의 저장값이 있으면 그 값 승계. |
| Show Total Spend(총 지출 표시) | 켜기 / 끄기 | 프로바이더를 합산한 [총 지출](/docs/dashboard.md#총-지출) 카드를 Priority·All Usage 탭 위에 공통으로 표시할지 여부.<br>기본값은 켜기이며, 기간별 비용·토큰 추적을 지원하는 프로바이더가 하나라도 켜져 있으면 카드 표시. |

대시보드에서 한도의 값이나 초기화 시각을 클릭해도 Show Usage As·Reset Times 전환.

## Alerts

### 경고 기준

Alerts의 **Thresholds** 기준을 Priority 탭, 메뉴 막대, 막대·링 색, Warning·Critical 알림에 공통 적용.

| 설정 | 옵션 | 동작 |
|---|---|---|
| Warning(경고) | 70% left ~ 20% left, 5% 단위 | 남은 비율이 Warning 기준 이하이고 Critical 기준보다 높으면 주황색으로 표시.<br>기본값은 30% left. |
| Critical(위험) | 25% left ~ 5% left, 5% 단위 | 남은 비율이 이 값 이하인 한도는 빨간색.<br>기본값은 10% left. |

Warning과 Critical은 Show Usage As가 Used여도 남은 비율을 정수 퍼센트로 반올림한 값 기준.
Critical은 항상 Warning보다 낮음 — 한쪽을 다른 쪽과 겹치게 옮기면 다른 쪽이 5% 밀림.

### 우선순위

경고·위험·빠른 소진·초기화 전 사용을 한 행씩 표시.
각 조건의 **Show in Priority(우선순위 표시)**와 **Receive Alerts(알림 받기)**를 개별 설정.
네 조건의 표시 기본값은 켜기, 알림 기본값은 끄기.
표시를 모두 끄면 대시보드의 탭 선택이 사라지고 **전체 사용량**만 표시.
조건 하나를 다시 켜면 **우선순위 / 전체 사용량** 탭 선택이 나타나고 기존 선택 탭 표시.
고정한 지표의 목록과 순서는 그대로 유지.

| 항목 | 우선순위 표시 | 알림 받기 |
|---|---|---|
| Warning(경고) | 켜면 잔량이 경고 구간인 한도를 소진 임박에 표시.<br>기본 구간은 잔량 10% 초과, 30% 이하. | 켜면 잔량이 Warning 기준 이하로 떨어질 때 통지. |
| Critical(위험) | 켜면 잔량이 위험 구간인 한도를 소진 임박에 표시.<br>기본 구간은 잔량 10% 이하이며, 다 쓴 한도는 소진됨에 표시. | 켜면 잔량이 Critical 기준 이하로 떨어질 때 통지. |
| Burning Fast(빠른 소진) | 켜기 / 끄기.<br>지금 속도면 초기화 전에 소진될 한도를 남은 양과 관계없이 Running Out에 표시.<br>메뉴 막대 자동 표시는 Running Out·Priority 선택에 적용.<br>한 번 표시되면 예상 기말 사용량이 한도의 90% 이하로 내려올 때까지 유지. | 켜기 / 끄기.<br>지금 속도면 초기화 전에 소진될 전망이면 통지.<br>예상 기말 사용량이 한도의 90% 이하로 내려가거나 실제 사용량이 0으로 회복되면 다시 통지 가능. |
| Use It or Lose It(초기화 전 사용) | 켜기 / 끄기.<br>초기화까지 24시간 이내이고 잔량을 정수 퍼센트로 반올림한 값이 50%를 넘는 한도를 Priority 탭의 별도 구역에 표시.<br>메뉴 막대 자동 표시는 Priority 선택에 적용하며, Pinned Only에서는 고정 여부에 따름. | 켜기 / 끄기.<br>같은 한도 조건에 새로 진입하면 통지. |

표시를 끈 조건에 해당해도 다른 표시 조건을 충족하면 해당 구역에 표시.
고정한 지표는 우선순위의 고정됨 구역에만 표시.
초기화 전 사용은 표시·알림 모두 하루보다 긴 주기(주간·월간 등)만 대상이며 5시간 세션과 달러 지출 상한은 제외.
설정 행과 실제 macOS 알림 제목 모두 Burning Fast(빠른 소진)로 표시.
초기화 시각이나 유효한 주기 정보가 없는 크레딧·한도는 완전 소진돼도 Burning Fast 알림에서 제외하며, 잔액 기준 Warning·Critical 알림은 유지.

### 알림

해당 알림을 켜고 macOS에서 egasu 알림을 허용하면 알림 조건을 충족할 때 통지.
앱이 메뉴 막대에서 실행 중이면 패널을 닫아도 알림 동작.

| 설정 | 옵션 | 동작 |
|---|---|---|
| Critical | 켜기 / 끄기 | 남은 비율이 Critical 임계값 이하로 내려가면 통지. 기본값 10%. |
| Warning | 켜기 / 끄기 | 남은 비율이 Warning 임계값 이하로 내려가면 통지. 기본값 30%. |
| Burning Fast | 켜기 / 끄기 | 현재 속도라면 초기화 전에 한도를 소진할 전망일 때 통지. |
| Use It or Lose It | 켜기 / 끄기 | 하루보다 긴 한도의 초기화가 24시간 이내로 남았고 잔량을 정수 퍼센트로 반올림한 값이 50%를 넘으면 통지. 달러 기반 한도 제외. |
| Quota Available Again | 켜기 / 끄기 | 같은 계정에서 소진된 한도를 다시 사용할 수 있다고 실측하면 한 번 통지. 기본 꺼짐. |
| Codex Reset Credit Expiry(초기화권 만료 알림) | 켜기 / 끄기 | 계정별 미사용 초기화권의 만료 24시간 전과 12시간 전에 각각 한 번 통지. 기본 꺼짐. |
| Codex Reset Watch | 켜기 / 끄기 | 공개 Reset Watch에서 새 유효 예측이나 리셋 예정 정보를 확인하면 통지. |

앞의 네 할당량 알림은 조건에 새로 진입할 때 통지하며 같은 상태에서 반복하지 않음.
Critical·Warning은 남은 비율을 정수 퍼센트로 반올림한 값 기준.
두 단계를 한 번에 넘으면 켜진 조건 중 Critical을 우선해 한 건만 통지.
egasu를 실행한 시점에 이미 나쁜 상태인 할당량은 통지 없이 기준선으로만 기록.
초기화 시각을 처음 확인한 것만으로는 새 기간이나 사용량 악화로 판정하지 않음.
카드의 계정 신원이 바뀌거나 제거되면 알림 기준선 초기화; 교체 계정의 첫 관측에서는 할당량 경고를 발생시키지 않음.
Claude 또는 Codex 카드의 계정을 식별할 수 없는 경우, 계정 목록 변경 시에도 해당 카드의 알림 기준선을 초기화하고 진행 중인 알림 중단.
계정 교체 시 이전 계정의 미제출 할당량 알림은 중단하고, 이미 제출 중인 요청은 완료 후 제거.
권한 확인 중 알림이나 프로바이더를 끄면 해당 요청 중단.
회복한 뒤 다시 나빠지면 알림 재활성화, 새 초기화 기간이 시작되면 초기화 기반 기록도 정리.
사용량이 0으로 돌아오면 빠른 소진 상태 회복으로 처리.
초기화 시각이 미래로 연장된 것만으로는 같은 기간의 중복 억제 기록을 지우지 않음.
**Critical·Warning**은 남은 비율 기준이며 초기화 기간이 없는 상한 잔액에도 동작.
**Burning Fast**는 초기화 기간의 사용 속도 정보가 필요하며, 예상 최종 사용량이 한도의 90% 이하로 내려가면 재활성화.
**Use It or Lose It**은 같은 기간에 한 번 통지하며, 실행 시 이미 해당 조건이면 통지 없이 기준선 기록.
사용량이 먼저 0으로 돌아와도 이후 초기화 시각과 주기로 새 기간의 시작이 확인되면 해당 기간에 다시 통지 가능.
데이터를 읽을 수 없는 지표는 알림 제외.
만료 시각을 아는 초기화권의 미래 알림만 macOS에 예약.
같은 워크스페이스에서도 Codex 사용자별로 예약과 초기화권 사용 기록을 구분.
앱을 다시 열면 첫 사용량 조회에서 사용자와 워크스페이스를 확인한 뒤 예약.
설정을 끄거나 서버가 초기화권 사용·사용 불가를 확인하면 해당 권의 남은 예약 취소.
서버가 전체 목록을 반환하지 않으면 선택한 권 한 장의 예약만 취소.
같은 시각에 만료되는 다른 미사용 권의 예약은 유지.
저장된 프로필의 인증으로 조회한 초기화권에는 해당 프로필 이름을 표시.
기본 인증 파일이나 Keychain 로그인으로 조회한 경우에는 Codex로 표시.
초기화권 사용 요청에서 일시적인 통신 오류가 나면 그 오류만으로 기존 예약을 취소하지 않음.
**Codex Reset Watch**는 할당량 경고·회복 알림과 독립적으로 동작.
egasu 알림은 같은 그룹으로 분류하며, 배너 표시 방식은 macOS 알림 설정에 따름.

**Quota Available Again**은 계정을 식별할 수 있는 Claude·Codex·Cursor 카드에서 최신 서버 사용량을 비교.
자동 또는 수동 조회로 같은 계정·지표의 소진과 이후 잔량을 차례로 확인하면 한 번 통지.
계정 미확인, 로컬 추정치, 다른 Mac의 사용 이력, 초기화 예정 시각 경과만으로는 통지 생략.
앱 재시작 후에는 새 관측부터 비교.

**Alerts → Other Notifications**에서 **Quota Available Again**, **Codex Reset Credit Expiry**, **Codex Reset Watch**를 개별 설정.
**Codex Reset Watch**는 Codex 프로바이더가 켜져 있으면 예측 지표를 숨겨도 알림만 사용 가능.
처음 켠 뒤 조회에서 현재 유효한 이벤트를 확인한 경우도 통지 대상.
기록이 남아 있는 공개 이벤트는 이 Mac에서 한 번 통지하며, 계정 수와 관계없이 같은 알림은 하나만 발생.
같은 이벤트의 확률·투표율·예정 시각 수정으로 반복하지 않으며, 예측 이후 리셋 예정 정보를 확인하면 추가로 한 번 통지 가능.
중복 방지를 위해 최근 확인한 이벤트 식별자 128개를 저장하며, 이 기록은 앱 재시작 후에도 유지.
조회 실패·취소, 만료된 예측, 이미 지난 리셋 예정 시각, 식별할 수 없는 이벤트는 알림 제외.
공개 예측을 알리는 기능이며 개인 계정의 사용량 리셋 완료를 의미하지 않음.
자세한 조건은 [Reset Watch](/docs/providers/codex.md#reset-watch) 참조.

모든 알림의 기본값은 꺼짐.
이전에 고른 알림의 켜짐·꺼짐 값 유지.
처음 하나를 켤 때 egasu가 알림 권한 요청.
허용·거부 응답이 끝난 뒤 현재 권한을 다시 읽어 안내 갱신.
macOS에서 egasu 알림이 꺼져 있으면 토글 아래에 "Notifications are off for egasu in System Settings." 안내 표시.
안내 행의 **System Settings**를 누르면 시스템 설정의 egasu 알림 페이지를 열고 패널 닫기.
아직 권한을 묻지 않은 상태면 **Allow Notifications(알림 허용)** 버튼 표시.
이미 거부한 상태에서는 허용 창을 다시 띄우지 않고 시스템 설정에서 변경.
알림 전달 시도마다 현재 macOS 권한을 한 번 더 조회해 허용·거부 변경 반영.
권한이 없으면 알림을 제출하지 않고, 할당량 알림의 전달 완료 기록도 남기지 않음.
재허용 뒤에도 할당량 알림 조건이 유지되면 다음 평가에서 다시 전달 시도.
최초 권한 요청은 공유하며, 별도 권한 조회 타이머나 반복 허용 창은 추가하지 않음.

알림 제목은 알림 이름이며 본문은 상태 설명.
할당량 알림의 부제목은 프로바이더와 지표이며, 등록된 Claude·Codex 계정은 계정명도 표시.
계정명 변경과 계정 전환은 이후 생성되는 알림에 반영.
알림 조건을 충족하는 계정은 All Usage 레이아웃이나 새 터미널 세션용 계정 선택과 관계없이 알림 대상.
Reset Watch의 부제목은 예측·예정 구분이며 계정명은 표시하지 않음.
알림을 누르면 패널의 대시보드 열기.

### Tokscale CLI 동기화

Tokscale 섹션의 **Usage Sync**는 로컬 사용량을 공개 Tokscale 프로필에 게시하는 기능.
iCloud 동기화, Share Anonymous Usage, 프로바이더 활성화, 일반 새로 고침과 독립.
앱이나 Settings를 여는 것만으로는 Tokscale 명령을 실행하지 않음.
`egasu` 명령과 로컬 HTTP API 요청도 Tokscale 실행을 시작하지 않음.
공개 범위는 [개인정보 및 사용 데이터](/docs/privacy.md#tokscale-공개-공유), 외부 서비스 정책은 공식 [Tokscale Privacy Policy](https://tokscale.ai/privacy) 참조.

#### 기기 이름

기기 이름 관리 버튼에서 **Tokscale Device Name** 창 열기.
이 창은 Tokscale에 전달할 이 Mac의 이름을 별도로 지정하는 기능이며, 기본값은 미지정.
이름은 앞뒤 공백을 제거한 뒤 비어 있지 않아야 하며, UTF-8 기준 최대 120바이트 허용.
제어 문자는 허용하지 않음.
저장한 이름은 이 Mac에만 보관하며, 이름 저장만으로 명령이나 네트워크 요청을 시작하지 않음.
창을 다시 열거나 앱을 재시작해도 저장한 이름 유지.
이후 제출 명령에 `TOKSCALE_DEVICE_NAME`으로 전달.
이 설정은 Tokscale의 기기 ID를 변경하지 않음.
전달한 이름의 공개 프로필 반영은 Tokscale CLI와 서버의 처리에 따름.

**Remove egasu Override**는 egasu에 저장한 이름만 제거.
Tokscale의 기존 공개 이름은 삭제하지 않음.
이후 제출에서는 egasu가 이름을 덮어쓰지 않으며, 환경 변수와 저장된 기기 기록의 이름 처리는 Tokscale에서 결정.

#### 사용량 제출

**Sync**를 선택하면 프로바이더·날짜·egasu 데이터를 명령 인자로 넘기지 않고 다음 명령을 한 번 실행:

```sh
bunx tokscale@latest submit
```

선택적 GitHub 별표 요청을 거절하도록 `n`과 줄바꿈을 한 번 전달한 뒤 입력 종료.
포함할 소스와 필드는 Tokscale에서 결정.
제출 항목에는 사용량·클라이언트·모델·기기·설정된 MCP 서버 이름 등 포함 가능.
제출 후 프로필은 공개되며 검색 결과에 노출될 수 있음.
제출 항목과 공개 범위는 [개인정보 문서](/docs/privacy.md#tokscale-공개-공유) 참조.
`@latest`는 egasu 출시 이후 동작이 바뀐 패키지를 내려받아 실행할 수 있음.
패키지 선택은 사용자 Bun 설정을 따르며, 홈 디렉터리 아래의 일치 패키지를 우선할 수 있음.

**Sync** 선택 후 앱의 처리 순서:

1. 앱 환경 변수의 `PATH`, 로그인 셸의 `PATH`, Bun 설치 경로에서 `bun`과 `bunx` 탐색.
2. Bun이 없으면 공식 설치 프로그램 실행.
   설치 중에는 **Installing Bun…** 표시.
3. 새로 설치한 경우에는 설치 경로의 `bun`과 `bunx` 검증.
   설치·검증 실패 시 제출을 중단하고 수동 설치 안내 표시.
4. 사용할 Bun이 확인되면 앱 재시작 없이 제출 명령 실행.
5. 명령이 0이 아닌 종료 코드와 `Not logged in.` 문구를 반환하면 **Log In…** 표시.
   그 밖의 0이 아닌 종료 코드는 일반 실패로 표시.

명령에는 앱과 로그인 셸에서 명시적으로 허용한 언어·네트워크·패키지 저장소·Tokscale 인증·설정·소스 경로 변수만 전달.
`HOME`과 작업 디렉터리는 현재 macOS 사용자의 홈으로 고정하고, 무관한 비밀 값과 미등록 변수는 제외.
저장한 기기 이름은 `TOKSCALE_DEVICE_NAME` 값만 덮어씀.
지원 소스 탐색은 Tokscale에서 수행.
추가 경로의 환경 변수가 허용 목록에 없으면 `TOKSCALE_EXTRA_DIRS` 사용.

#### 로그인 후 다시 제출

로그인 전 안내에는 GitHub 신원 정보 저장, 공개 프로필의 사용자명·아바타·표시 이름 노출 가능성 포함.
로그인 명령은 개인 토큰 이름으로 `CLI on <hostname>` 사용.

1. **Log In…**을 선택해 **Log In to Tokscale** 창 열기.
2. 창 안의 **Log In** 선택.
   앱은 표준 입력 없이 `bunx tokscale@latest login`을 한 번 실행.
3. 승인 대기 중 표시되는 브라우저 주소와 사용자 코드로 로그인 승인.
4. 로그인 창에 완료 상태가 표시되면 **Done**으로 창 닫기.
5. Settings 카드의 **Tokscale Login Finished. Sync Has Not Started.** 표시 확인.
6. 사용량을 제출하려면 카드의 **Sync**를 다시 선택.

로그인 완료만으로 사용량을 자동 제출하지 않음.
만료되거나 폐기된 저장 인증 정보는 egasu의 로그인 안내로 복구되지 않을 수 있으므로 Tokscale 자체 CLI에서 복구.

#### 결과와 재실행

동시에 Tokscale 명령 하나만 실행.
카드에서 Bun 설치 중·명령 실행 중·로그인 필요·완료·실패 상태 구분.
명령 출력은 ANSI·제어 시퀀스를 제거하고 크기를 제한해 표시.
완료·실패 후에도 Settings 카드의 **Done**으로 닫거나 다음 작업을 시작하거나 앱을 종료할 때까지 출력 유지.
로그인 창이 열려 있으면 같은 로그인 출력 표시.

Settings 카드의 **Done**은 결과·명령 출력·오류를 비우고 초기 카드로 복귀.
로그인 창의 **Done**은 창만 닫으며 카드의 결과와 출력은 유지.
기기 이름과 Tokscale 인증은 유지하며, 설치·명령 실행 중에는 Done 사용 불가.
제출 명령의 종료 코드가 0이면 결과를 닫기 전까지 **Sync** 비활성화.
**Done**으로 결과를 닫은 시점부터 최소 10분간 비활성화 유지.
**Sync Available at**은 다음 실행 가능 시각 표시.
해당 시각에는 버튼만 활성화하고 자동 제출하지 않음.
오류·미로그인 안내·로그인 결과를 닫으면 새 대기 시간 없이 사용자가 재시도 가능.
대기 상태는 Settings를 닫아도 유지하며 앱 재시작 시 초기화.
종료 코드 0은 제출할 사용량이 없는 경우에도 가능하므로 업로드 성공을 보장하지 않음.

#### Bun 자동 설치 조건

Bun이 없을 때만 공식 [설치 프로그램](https://bun.com/docs/installation) 실행.
현재 사용자 홈 아래에서 앱의 경로 검증을 통과한 `BUN_INSTALL`, 또는 기본값 `~/.bun`에 설치.
설치 프로그램은 로그인 셸 설정 파일을 갱신할 수 있음.
조건에 맞지 않는 `BUN_INSTALL`은 수정하지 않고 실패와 수동 설치 안내 표시.
사용 가능한 기존 Bun은 교체하지 않음.
기존 설치 탐색은 심볼릭 링크나 사용자 홈 밖의 경로도 허용하며, 홈 경로 제한은 자동 설치에만 적용.
Bun은 있지만 사용 가능한 `bunx`가 없으면 재설치하지 않고 오류 표시.

## Labs

**실험실** 탭은 **베타 업데이트**를 켠 동안에만 표시.
실험 기능은 변경되거나 없어질 수 있으며, 사용할 기능을 탭 안에서 개별 선택.
실험실을 보는 중 베타 업데이트가 꺼지면 **일반** 탭으로 이동.

### 계정 전환 추천

Claude·Codex의 사용량이 설정한 기준에 도달하면 다른 계정으로 전환하도록 추천하는 기능.
자동으로 계정을 바꾸지 않으며, 전환 전에 사용자 확인 필요.
설정과 닫은 추천의 계정·세션 정보는 이 Mac에 저장.

| 설정 | 선택지 | 동작 |
|---|---|---|
| 활성화 | 켜기 / 끄기 | 기본값 끄기. 켜면 현재 계정과 후보 계정의 사용량 평가. |
| 추천 시작 사용률 | 1%–100% 정수 | 기본값 95%. 현재 계정의 기본 한도 중 하나라도 이 값 이상이면 후보 확인. |
| 후보 사용률 제한 | 1%–100% 정수 | 기본값 90%. 후보의 적용 가능한 모든 기본 한도가 이 값 미만일 때만 추천. |

활성화하면 두 사용률 기준 표시.
사용률은 Enter를 누르거나 입력란의 포커스를 벗어나면 적용.
잘못된 입력은 안내를 표시하고 마지막으로 저장한 값 유지.
두 사용률 기준은 대소관계 제한 없이 각각 적용.
후보 순위는 세션·주간 초기화가 빠른 계정 우선.

후보의 5시간·주간 등 적용 한도가 하나라도 후보 제한 이상이면 제외.
5시간 세션이 0%·시작 전이어도 주간 한도는 별도로 검사.

A에서 B로 전환하는 추천을 **×**로 닫으면 A를 사용하는 동안 모든 추천 숨김.
C로 전환한 뒤에도 B는 후보에서 제외하며, 다른 적격 계정은 추천 가능.
원래 A 또는 B의 5시간 세션 초기화가 확인되면 해당 차단 해제 후 현재 조건 재평가.
C의 세션 초기화는 A→B 차단에 영향 없음.
초기화 시각이 없으면 다음 정상 조회에서 재확인하며, 시작 전 세션의 첫 시작은 초기화로 처리하지 않음.
화면 이동·앱 재시작·기능 끄기와 켜기 후에도 차단 유지.
여러 추천의 차단은 각각 관리하며 다른 프로바이더에는 적용하지 않음.
베타 업데이트를 끄면 추천도 꺼지고, 다시 켜도 자동 활성화하지 않음.
사용률 기준·닫은 추천의 차단은 유지하며 다시 사용하려면 실험실에서 활성화.
승인 시 활성화 상태·사용률 기준·추천 차단 상태를 다시 확인.
더 이상 유효하지 않은 추천은 대상 인증을 적용하기 전에 중단.

추천 대상과 사용량·신원 검증은 [계정 전환 추천](/docs/dashboard.md#계정-전환-추천) 참조.

### 소프트 한도

구독에 포함된 주간·월간 사용량이 사용자가 정한 비율에 도달했는지 확인하는 기능.
설정은 이 Mac에 저장.

| 설정 | 선택지 | 동작 |
|---|---|---|
| 활성화 | 켜기 / 끄기 | 기본값 끄기. 켜기 전에 확인 창 표시. |
| 사용량 기간 | 주간 및 월간 / 주간 / 월간 | 기본값은 주간 및 월간. 선택한 기간의 구독 한도에 기준 적용. |
| 기준값 | 1%–100% 정수 | 기본값 90%. Enter를 누르거나 입력을 마치면 적용. 범위를 벗어난 입력은 안내를 표시하고 기존 값 유지. |

사용량 기간과 기준값은 소프트 한도를 켜면 표시.
기존에 5시간을 선택한 Mac은 주간 및 월간을 적용하고, 주간을 선택한 Mac은 주간 설정 유지.
베타 업데이트를 끄면 소프트 한도와 사용량 관측이 꺼지며 기간과 기준값은 유지.
앱 시작 시 베타 업데이트가 꺼져 있는 경우도 동일하게 처리.
다시 사용하려면 실험실에서 활성화.

#### 지원하는 사용량

같은 계정에 주간 전체 한도와 모델별 한도가 있으면 각각의 사용량과 상한으로 계산.
사용량 또는 잔량으로 표시할 때 기준선 위치는 [대시보드의 사용량 막대](/docs/dashboard.md#한도가-있는-지표) 참조.

| 프로바이더 | 주간 | 월간 |

| Claude | 전체·Fable·Sonnet | — |
| Codex | 기본·Spark | 기본·Spark |

| Antigravity | Gemini 풀·Gemini 외 풀·Argon | — |
| Copilot | — | 상한이 있는 개인 크레딧·채팅·코드 완성 |
| Devin | 주간 할당량 | — |
| Grok | 공유 크레딧 한도 | 공유 크레딧 한도 |
| Kimi | `usages`의 `limit_7d` 또는 기존 `usage`의 주간 할당량 | 총사용량 |
| Kiro | — | 크레딧 |

요금제와 조회 결과에 따라 실제 표시되는 항목은 달라짐.
예를 들어 Kimi에서 월간 총한도만 제공하는 요금제는 **총 사용량**에 월간 기준 적용.
OpenRouter의 기간별 지출과 키별 지출 상한은 종량제 항목으로 대상에서 제외.
OpenCode Go 서버 조회가 실패하면 이 Mac의 달러 추정치에는 안내선만 표시.
5시간 세션 사용량은 대시보드에서 계속 확인 가능.
일간 사용량, Reset Watch 예측, 종량제 잔액, 추가 지출 상한, 최근 30일 비용 합계는 소프트 한도 대상에서 제외.

**한도 상태**를 펼치면 선택한 기간을 지원하는 활성 계정별 상태 확인.
한 계정에서 대상 지표 하나라도 기준값에 도달하면 해당 계정에 도달 상태 표시.
구독 한도 판정에는 유효한 실측 사용률을 사용하며, 반올림한 표시값이나 여러 지표의 합계를 사용하지 않음.
앱이나 CLI의 조회가 실패하면 이전 실측값으로 새 취소를 실행하지 않음.
OpenCode처럼 최근 정상 조회의 로컬 추정치만 있으면 **추정 사용량**, 판정할 데이터가 없으면 **한도 미확인** 표시.
같은 계정의 실측 한도마다 초기화 시각을 따로 적용.
로그인이나 인증 정보가 바뀐 카드는 다음 정상 조회까지 한도 미확인으로 표시.
다른 카드에서 확인한 유효한 한도는 유지.
기준에 도달한 유효한 한도가 없고 선택 기간의 한도 조회가 불완전하거나 일부 값이 만료되면 한도 미확인으로 표시.
별도로 조회하는 사용 이력이나 비용만 실패하면 확인한 구독 한도로 판정.

**터미널 명령 → 명령 복사 → CLI 시작**에서 Codex·Claude·Kimi의 사전 검사 명령을 복사해 터미널에서 실행.
한도에 도달했거나 확인할 수 없으면 복사한 명령은 새 세션을 시작하지 않음.
**한도 확인**은 지원 프로바이더의 상태만 조회하는 명령을 복사.
자세한 동작과 종료 코드는 [소프트 한도 확인](/docs/cli.md#소프트-한도-확인) 참조.
실행 중인 작업을 자동 취소하려면 해당 작업과 사용량이 같은 계정·구독 한도에 속하는지 확인할 수 있는 연결 필요.
현재 앱에는 이 조건을 충족하는 제어 연결이 없어 기준을 넘겨도 기존 대화는 계속 진행.

### 명령줄

**터미널 도우미**(Terminal Helper)의 **설치…**를 누르면 macOS 관리자 승인 후 앱에 포함된 `egasu` 명령 연결.
앱이 링크 대상과 실행 가능 여부를 확인한 뒤 **제거** 버튼 표시.
제거할 때는 앱의 확인창에서 한 번 더 **제거**를 선택한 뒤 macOS 관리자 승인 필요.
같은 경로에 다른 파일이 있으면 **사용 불가**(Unavailable) 표시 후 해당 파일 유지.
설치·제거가 실패하면 실험실에 오류 표시.
다른 탭에서 돌아와도 처리 결과 안내 유지.
베타 업데이트를 꺼도 설치한 명령은 계속 사용 가능.
링크를 제거하려면 베타 업데이트를 다시 켠 뒤 실험실에서 **제거** 선택.
명령 사용법과 설치 절차는 [CLI](/docs/cli.md#path에-설치) 참조.

## 버전

앱 버전은 패널 푸터에 표시.

업데이트 후 레이아웃, 고정, 환경 설정, 전역 단축키 보존.
저장한 Priority 고정 목록이 있으면 빈 목록도 그대로 유지.
목록이 없으면 첫 실행에 한 번 기존 메뉴 막대의 사용자 지정 별표를 [Priority 고정으로 이전](/docs/menu-bar.md#고정과-이전-별표).
업데이트로 설정 저장 방식이 바뀌면 실행 시 기존 설정을 제자리에서 업그레이드하고, 중간 버전을 몇 개 건너뛰었다면 해당 단계도 순서대로 적용.
업데이트 시 전체 설정 초기화 없음.

켜 둔 프로바이더도 업데이트 후에 그대로 유지 — 사용자 선택을 덮어쓰지 않음.
완전히 새로 설치한 경우에는 Mac의 로컬 인증 정보나 사용 흔적으로 처음 켤 프로바이더 결정([대시보드 § 첫 실행](/docs/dashboard.md#첫-실행) 참조).
업데이트로 새 프로바이더가 추가되면 해당 프로바이더만 같은 기준으로 한 번 확인.
로컬 감지 조건을 만족하면 자동으로 켜고, 기존 프로바이더의 선택은 유지.
[활성화되는 프로바이더](/docs/provider-enablement.md) 참조.
